Закрытие вкладки агента убирает её из раскладки и сохраняет чат в Диалогах.
Работающий агент продолжает ход в фоне. Клик по Диалогу открывает вкладку снова;
архивировать чат можно в меню Диалогов 0.9.0. Скрытые вкладки сохраняются на клиенте
между перезагрузками окна. Это поведение проверено с клиентом Paseo 0.13.0;
при неизвестной форме внутреннего стора закрытие остаётся родным.

Навигация по вкладкам папки, когда их много.

Paseo сжимает вкладки до 64 px, а дальше прячет их за край ленты, и листать её можно только тачпадом. Плагин:

- не сжимает вкладки: название видно целиком, до 160 px, лишнее уходит в прокрутку;
- листает ленту обычным колесом мыши;
- сам доводит ленту до открытой вкладки, в том числе после переключения клавишами;
- показывает по краям, сколько вкладок спрятано слева и справа, и отмечает, если там кто-то ждёт ответа, упал с ошибкой или закончил работу; клик листает на экран;
- показывает на вкладке чата две маленькие синие крутилки, когда сам чат стоит, а работают его подагенты (как в плагине "Диалоги"), с подсказкой "Работают подагенты: N"; та же метка видна за краем ленты и в списке вкладок. Запрос разрешения и ошибка важнее и остаются родными;
- добавляет в конец ленты кнопку со счётчиком: список всех вкладок по порядку, с поиском по названию, статусами и подсказками родных клавиш перехода.

Работает в настольном приложении и веб-версии Paseo 0.12. Штатного API для ленты вкладок у плагинов нет, поэтому плагин опирается на разметку Paseo; если она изменится, плагин ничего не трогает и лента остаётся родной. На телефоне у Paseo свой список вкладок, плагин там ничего не меняет. Для индикатора подагентов плагин читает список агентов своего хоста через API Paseo. Плагин ничего не отправляет и не хранит.
