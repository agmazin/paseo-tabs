# Вкладки

Навигация по вкладкам Paseo Desktop и веб-клиента: прокрутка, список вкладок,
закреплённая кнопка "+", индикатор работающих подагентов.

В 0.4.1 крестик вкладки чата открывает диалог:
- "Закрыть" (зелёная кнопка) - убрать выбранную вкладку, сохранить чат в Диалогах и продолжить работу;
- "Архивировать" (оранжевая кнопка) - архивировать только после этого выбора;
- Крестик справа сверху или Escape - оставить состояние как было.

Выбор не запоминается. При ошибке диалога, неизвестном адаптере или смене вкладки
действие отменяется. Быстрые повторные клики не создают очередь действий.
Закрытие последней вкладки сохраняется после reload; повторное открытие снова требует выбора.

Общий runtime используется плагином и штатным обработчиком. Версионный патч клиента
защищает до загрузки плагина и при его отключении. Плагин совместим с Paseo >=0.12.0 <0.15.0,
патч проверен только для точного bundle Desktop/web 0.14.0. На нативном iOS/Android
этот DOM-адаптер не запускается.

Полный протокол: docs/verification-0.4.1.md. Старое автоматическое восстановление
архивов удалено: явный архив не отменяется фоновым обработчиком.
