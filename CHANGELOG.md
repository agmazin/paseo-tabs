# 0.4.2

- Штатные AdaptiveModalSheet, SheetHeaderIconButton с Lucide X и Button клиента Paseo 0.14.0 вместо DOM-имитации.
- Штатные тема, геометрия, заголовок, compact sheet и кнопки; зелёная "Закрыть", оранжевая "Архивировать".
- Крестик без фона и постоянной рамки; равные визуальные отступы сверху и справа, кольцо только при клавиатурной навигации.
- Видимость контролов проверяется по hit testing и стилям предков; скрытое окно не может подтвердить действие.
- Native миграция с точной пары 0.4.1, отказ от неизвестных SHA, идемпотентность и откат к исходной паре.
- Обновление открытого native 0.4.1 renderer через plugin reload без перезапуска UI.

# Changelog

## 0.4.1 - 2026-10-31

- Архивные root/child закрываются локально без диалога и archive/resume/unarchive RPC.
- Смена archivedAt при открытом диалоге отменяет устаревший выбор; неизвестный статус блокирует действие.
- Отмена перенесена на крестик справа сверху; Escape и крестик только отменяют.
- Зелёная кнопка "Закрыть", оранжевая "Архивировать".
- Начальный фокус на крестике, видимая рамка фокуса, доступное имя, циклический Tab.
- Точное обновление native 0.4.0 до 0.4.1 с сохранением прежней пары bundle/index для отката.

## 0.4.0 - 2026-10-31

- Каждый крестик вкладки чата требует выбора "Закрыть вкладку", "В архив", "Отмена".
- Escape, смена фокуса, ошибка открытия диалога и неизвестный адаптер отменяют действие.
- Штатный обработчик и перехватчик используют один runtime. Повторные клики не ставят действия в очередь.
- Версионный патч Paseo Desktop/web 0.14.0: точные SHA-256, проверка трёх замен,
  backup, rollback, идемпотентность, смена ключа кеша bundle.
- Последняя закрытая вкладка остаётся скрытой после reload, чат сохраняется вне архива.
- Удалены журнал намерений, backend восстановления и приватный same-ID import.
- Добавлены CI, проверки установки и живая матрица на отдельном демоне с fixtures.
