# Paseo "Вкладки"

Плагин Paseo: навигация по вкладкам рабочего пространства, когда их много (15-20 и больше).

Состояние на 21.10.2026: только макеты, ждут одобрения Александра. Код и установка - после одобрения,
отдельным плагином (Диалоги, Лимиты и Канбан не трогаем). Задание - `docs/source/2026-10-21-task.md`.

- `prototype/live.html` - живой макет: переключатель "Сейчас в Paseo" / А / Б / В, колесо мыши над лентой,
  ⌥⇧[ ] и ⌘⌥1-9 как в Paseo, кнопки "Тендеры просят ответ" и "Открыть новый чат".
- `prototype/shots/` - снимки для показа в чате; перерисовать - `prototype/shots.sh` (безголовый Chrome
  со своим профилем в /tmp, состояние экрана задаётся в `#hash` адреса).

Варианты:
- А. Листалка: колесо мыши листает ленту, лента сама доезжает до активной вкладки, вкладки не сжимаются
  (название целиком, до 160 px), по краям счётчики скрытых "‹ 10" и "3 ›" с "!", если за краем ждут ответа.
- Б. (рекомендован) А плюс кнопка со счётчиком в конце ленты: список всех вкладок по порядку, поиск, статусы.
- В. Вкладки в несколько строк (как wrapTabs в VS Code).

Что есть в Paseo 0.12.0 (по коду приложения, `computeWorkspaceTabLayout` и `workspace-tabs-scroll`):
- вкладки сжимаются до 64 px (максимум 160), потом лента становится горизонтальным ScrollView без полосы
  прокрутки, с тенями по краям (`HorizontalScrollBoundaryShades`); листается только тачпадом вбок или
  Shift+колесо; автопрокрутки к активной вкладке нет;
- ⌘⌥1-9 - вкладка по номеру, ⌥⇧[ / ⌥⇧] - соседняя, ⌘K ищет чаты; Ctrl+Tab свободна;
- список вкладок (`MobileWorkspaceTabSwitcher`) есть только в мобильной раскладке.

Что позволяет плагин:
- штатно - `addHeaderButton` (поповер в шапке пространства) и пункты Command Center; API для самой ленты нет;
- остальное - `client/web.ts` под `Platform.OS === "web"`, как в Лимитах: метки `workspace-tabs-scroll`,
  `workspace-tab-<kind>_<id>` и `aria-selected`; меток нет - плагин ничего не делает, кнопка списка
  уходит в шапку через `addHeaderButton`;
- ширина вкладок - только правкой стиля; первым делом проверить на тестовом демоне перетаскивание вкладок.
